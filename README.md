# FPV 离线社区与 3D 探索

## GitHub Pages 在线版

访问 **https://djkuuki.github.io/GreetRC/**。GitHub Pages 从 `gh-pages` 分支根目录发布静态文件；`main` 分支保存源码和开发工具。

更新源码并提交后，运行 `npm run deploy:pages` 重新构建并推送发布分支，GitHub 会自动更新在线站点。发布命令需要 Git、Node.js 和已登录的 GitHub CLI（`gh auth login`）。仅构建使用 `npm run build:pages`，输出位于忽略的 `dist/` 目录；`npm run test:pages` 使用纯静态服务验证项目子目录路径、3D 资源、深层页面、发布与刷新。

静态构建会生成社区页面和所有示例内容的独立入口，支持直接打开和刷新。用户在浏览器里创建的内容通过 `site.html?route=…` 打开，仍只保存在当前浏览器中；静态托管不提供多人共享、真实账号或服务端数据库。本地离线启动方式继续可用。

### 首页加载与模型缓存

首页先显示 GREET RC 字标加载页，提供实际准备进度、深浅主题、手机布局与失败重试。四个机型合计约 25 MB，全部下载、解码、涂装及 GPU 预热完成后才展示首页。首次等待集中在加载页；同一次页面打开期间复用已经准备好的模型、旋翼和贴图，切换时不重新下载或解码，也不重复生成直升机涂装。刷新或重新打开首页会重新准备模型，文件下载是否命中缓存由浏览器决定。

`npm run test:preload` 验证全机型进入门槛、断网后连续切换、显存资源数量稳定、失败时仅重试缺失模型，并生成桌面、手机与暗色加载页截图。测试需要先运行 `node server.cjs`；`npm run test:pages` 同时验证静态发布目录中的加载流程。

模型新增了白蓝配色与额外机尾天线，默认展示 `assets/fpv-drone3-v3-white-blue.glb`。查看器两侧的大箭头可循环切换白蓝穿越机、原始穿越机、运动固定翼与运动涂鸦直升机，并播放飞出、飞入动画。支持键盘左右方向键，系统减少动态效果时直接切换。原文件未覆盖；可重复编辑的 Python 脚本与用法见 `tools/MODEL_EDITING.md`。新模型为 14 个部件，原模型仍为 13 个。

双击 **启动离线版.cmd**，浏览器会打开 http://127.0.0.1:4173 。保留启动窗口，关闭窗口即停止服务。当前电脑已安装 Node.js；复制到其他电脑时也需 Node.js。网站与模型运行不需要安装 npm 包，也不需要联网；跳转官方下载网站时需要联网。

不要直接双击 index.html：浏览器的模块和模型加载需要通过本地 HTTP 服务。

### 离线交互与数据

发布、草稿、评论、点赞、收藏、投票和演示资料存入当前浏览器的 `localStorage`，键名为 `fpv-community-v1`。刷新后保留；换浏览器、端口或清理站点数据后不会自动迁移。资料设置中可导出 JSON 或重置本演示数据。

登录只建立本地演示身份，不保存密码，不发送短信或邮件；验证码固定为 `123456`。没有多人后端、真实账号认证、跨设备同步或第三方安装包。工具页面通过新标签页打开相应软件的官方资源。PID 页使用简化曲线演示交互，不是实际飞控仿真。

## GREET RC 技术交流平台 · 三语界面

全站名称为 GREET RC技术交流平台。右上角支持中文、English、Tiếng Việt 即时切换。语言保存在 `greet-rc-language`，也可用 `?lang=zh`、`?lang=en`、`?lang=vi` 指定。切换不刷新页面，保留未提交输入与 3D 模型状态；跨页面、筛选和搜索继续使用所选语言。现有 `fpv-community-v1` 本地数据键保留，已有内容无需迁移。

- 中文：http://127.0.0.1:4173/?lang=zh
- English：http://127.0.0.1:4173/?lang=en
- Tiếng Việt：http://127.0.0.1:4173/?lang=vi

`messages.js` 提供本地三语词条，`i18n.js` 负责文本、无障碍标签、占位文字和动态消息的本地化。分类参数与表单选项值保持原有内部标识，避免切换语言破坏过滤和已有数据。用户发布的正文、标题、昵称、回复和草稿保留原文，不进行自动翻译。所有语言资源均随站点保存，不依赖外部翻译服务。新增界面文案时应补齐三语词条，并对用户内容使用 `translate="no"`。

验证：`npm run test:i18n` 检查即时切换、跨页面持久化、草稿、原文保护、分类值、搜索、3D 部件说明和手机布局；同时检查 74 个入口的英语和越南语界面是否漏译。`npm test` 验证 3D 首页和社区原有功能。

### 独立旋翼与对称涂装

`aircraft.js` 根据模型已有子网格设置旋转轴心，不切割或增加网格：无人机的四个 `propeller*` 子网格绕各自电机轴旋转；直升机的 `Rotor_3` 绕主轴、`Tail_2` 绕尾轴旋转。电机外壳、固定机构和起落架保持不动。切换时在模型准备完成后，同时启动桨叶、转向与水平位移。新旧两架使用同一渲染器交叠进出，整段飞行动画约 1150 毫秒。固定翼同样转向并移动；其前桨未独立分组，按要求保持静止，不切割几何。

直升机涂装仅应用于 `canopy_0`。两侧使用相同纵向/高度坐标，色块与线条镜像对称；字标分别处理以保证两侧可读。桨叶为石墨色，起落架为银白色。原 GLB 文件保持不变。

`node tests/rotor-livery.cjs` 检查独立旋转、固定结构不动、网格数不变和纯色部件；`/tools/helicopter-preview.html` 提供近景检查。
